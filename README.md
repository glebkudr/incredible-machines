# Невероятные машины — файлы моделей

Интерактивные модели исторических машин, в которых всё движется по физике. Страница проекта:
https://glebkudr.com/projects/incredible-machines

Здесь лежат только файлы, которые загружает плеер: движок Godot (`engine/godot-<версия>/`) и пакеты
машин по версиям (`<машина>/<версия>/`). Те же файлы лежат на сайте как запасной источник: если
GitHub Pages не отвечает, плеер берёт их оттуда. Версия машины — хеш её пакета и данных, поэтому
файлы одной версии никогда не перемешиваются; `manifest.json` называет текущие версии.

Отдельно модель открывается по адресу https://glebkudr.github.io/incredible-machines/newcomen/
